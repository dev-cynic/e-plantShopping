🌿 Paradise Nursery Shopping Cart Application

Welcome to the Paradise Nursery plant shopping web application.
This project was created as part of the IBM Front-End Developer / React Final Project Submission.
It demonstrates React components, hooks, Redux Toolkit, dynamic UI rendering, and GitHub Pages deployment.

📌 Project Overview

Paradise Nursery is a React-based shopping cart application where users can browse a variety of indoor houseplants, add them to a shopping cart, adjust quantities, and view total pricing.

This project demonstrates:

React functional components

Component composition

React Hooks (useState, useEffect)

Redux Toolkit for global state

Rendering dynamic arrays using map()

Event handling & conditional rendering

Cart quantity updates

Total cost calculations

GitHub Pages deployment
